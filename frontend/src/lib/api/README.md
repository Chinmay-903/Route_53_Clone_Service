# Generated API client — do not hand-edit

Every file in this directory is generated by `@hey-api/openapi-ts` from
`frontend/openapi.json`, which is exported from the FastAPI application's own
schema.

Regenerate after any API change:

```bash
npm run generate:api
```

Edits made here are lost on the next generation. To change the client, change
the API and regenerate. CI performs both steps and then runs `tsc --noEmit`, so
a breaking contract change fails the build rather than reaching the browser.
